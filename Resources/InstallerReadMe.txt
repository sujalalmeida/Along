TileMe
Your windows, in one scrolling row.

INSTALL
1. Drag TileMe into Applications.
2. Eject this disk image, then open TileMe from Applications.
3. Enable Accessibility access when TileMe asks.
4. Close setup and press Control + Option + P to start your row.

REQUIREMENTS
Apple Silicon Mac (M1 or newer), macOS 13 or later.

ABOUT THIS DOWNLOAD
This is a free, open-source preview build. It is ad-hoc signed, not
Developer ID verified or notarized by Apple. macOS may block first launch.
After attempting to open it, look in System Settings > Privacy & Security
for Open Anyway if you trust this download. Follow Apple's instructions:
https://support.apple.com/102445
Managed Macs may prohibit opening unverified apps. Do not disable Gatekeeper.

SHORTCUTS
Control + Option + Left / Right   Previous / next window
Control + Option + R              Cycle the selected window's width
Control + Option + P              Start / stop and restore windows
Control + Option + horizontal scroll   Move along the row

Stop & restore windows or Quit TileMe from the menu bar to restore your
original window positions. Force-quitting cannot restore them.

ACCESSIBILITY
In Privacy & Security, enable TileMe under Accessibility (called Device
Control and Data Access on newer macOS). Grant access to the installed
copy in Applications. If an update leaves access denied, remove the old
entry with the minus button, add the installed TileMe with plus, and enable it.

UPDATING
Quit TileMe from its menu before replacing it in Applications. Keep one
installed copy. Ad-hoc signed updates may need a fresh Accessibility grant.

UNINSTALL
Quit TileMe from its menu, remove its Accessibility entry, and move
/Applications/TileMe.app to the Trash. Remove it from Login Items if added.

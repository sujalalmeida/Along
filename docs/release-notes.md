# TileMe 0.6.0 preview

A scrolling row for your Mac windows, with keyboard navigation and continuous trackpad scrolling. Free and open source.

- Apple Silicon (M1 or newer), macOS 13 or later.
- Original app icon and drag-to-Applications DMG; ZIP also included.
- Spring motion that can respond to new input mid-animation.
- Width cycling, automatic window insertion, and restoration when stopping or quitting.

This preview is **ad-hoc signed and not notarized by Apple**. macOS may block first launch. Follow the installation notes and Apple's per-app Open Anyway instructions if you trust the download. Accessibility access is required to arrange windows.

One display/current Space per session. Application size and position limits can affect placement. A force-quit cannot restore saved positions.

Fresh-install testing on another Mac and on the oldest supported macOS version is pending. This package is a release candidate, not a claim of completed compatibility testing.
